## Organizing the Development Process

| Stage | Objective & Deliverable |
| --- | --- |
| **Scope** | Understand how to add a category and handle all related operations (delete, update, and display). |
| **Design** | Define the database structure for the `category` table (`id`, `name`, `color`, etc.), design the API structure, and outline the required form fields. |
| **Develop** | Create the SQL table, build the web page with an HTML form (including client-side validation) and a table to display categories, and implement all API CRUD endpoints (`POST`, `GET`, `PUT`, `DELETE`). |
| **Test** | Verify that all operations (Create, Read, Update, Delete) function correctly, and log any encountered errors (or 0 if none). |
| **Validate** | Confirm that the feature matches the expected requirements and stays within the original plan without scope creep. |
